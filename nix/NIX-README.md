## Notes about SPEX and NIX

SPEX was born a fork of a Nix-based project by Fareed Zakaria, originally
called "SELF". The Nix related files in this repository are inherited
from that project, but aren't maintained (or even considered) as part of
the SPEX work. 

This may change, but the author doesn't use Nix/Guix and for the moment
has no way to use, much less test, any of these files.

- mhoye, Oct 2026
